# Shamima Sultana — QA Portfolio

Personal QA portfolio and tutorial site. Plain HTML/CSS/JS — no build step, no dependencies.

## Structure
- `index.html`  — home / landing page
- About pages:  `about.html`, `skills.html`, `certifications.html`, `research.html`, `achievements.html`
- `projects.html`
- Learn (courses): Playwright (PWHub + modules), k6 (K6Hub, K6, K6Course), JMeter,
  SQL (SQLHub, SQLCourse), Manual, API, AITest, DevTools, Git, Selenium, MobileTest,
  A11y, Security, and their sub-modules
- More:  `News.html`, `Interview.html`, `ISTQB.html`
- `assets/`  — images

Every page shares a top navigation bar with dropdown menus.

## Publish / update on GitHub Pages
1. Repo: `ShamimaSultanaMiley.github.io`
2. Delete the old files, then upload ALL files here (keep the `assets` folder).
3. Commit to `main`. Pages is already enabled.
4. Live at https://shamimasultanamiley.github.io within 1–2 minutes.

## Test locally
    python -m http.server 8000
Then open http://localhost:8000

## Notes
- Best viewed on desktop; a mobile layout pass can come later.
- The dropdown menus work on hover (desktop) and via the "Menu ☰" button (narrow screens).
